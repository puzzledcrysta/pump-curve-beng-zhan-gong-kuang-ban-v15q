# 泵站工况板数据字典

## 来源文件

| 字段 | 定义 |
|---|---|
| 工况单 | 文本主键，保留前导零。跨业务键不汇并记录。 |
| 修订号 | 正整数。最高版优先；最高同版字段冲突或存在同版、更新版的未采信记录时隔离，旧版无法接替。 |
| 提交时间 | ISO 8601，必须带 UTC 偏移量。标准化后展示 UTC。 |
| 原始备注 | 可空，允许引号内换行。 |
| 泵组曲线、管线曲线 | 必填字段。多项字段用半角分号隔开，显式空集合用 `无`。 |

识别 `UTF-8`、UTF-8 BOM 与独立的 `GB18030` 文件。`业务编号`、`版本`、`更新时刻`、`备注` 为旧版表头别名。新旧名同时出现会被拒绝。`-`、`N/A`、`NULL`、`未知` 和空串均按必填值缺失处理。物理行号指 CSV 逻辑记录起始行。

## 计算字段

泵曲线写 `泵名=流量:扬程,流量:扬程`，多台泵用分号。管线曲线只写同样的测点。

仅在全部泵的公共实测扬程内插值；泵流随扬程严格下降，管线扬程随总流量严格上升。无交点时不得外推。

数值在服务端以十进制定点方式计算，对外按字符串传输。单文件上限 128 KiB，复合字段最多 240 个项目，个别字段还有业务上限。格式无法恢复的 CSV 整批拒绝，列数、缺字段、来源冲突和业务条件错误逐条隔离。

## 复算与外部清单

外部清单包含 `工况单` 和 `外部记录值(立方米/时)`，允许省略不在对账范围内的键。同一键重复会拒绝该清单。结果数值单位为 **立方米/时**。差值按本次复算减外部记录，缺一侧时差值计算以 0 占位并保留缺失原因。

### 舍入外部账

外部账只给四舍五入后的显示值时，改用四列表头：`工况单,外部记录值(立方米/时),舍入步长(立方米/时),允差(立方米/时)`。两列要么同时出现（四列），要么都不出现（原两列精确账）；步长必须为正、允差非负，否则整份清单按 `TOL_FORMAT` 拒绝。

显示值 `b` 按步长 `s` 四舍五入，外部真实值落在闭区间 `[b-s/2, b+s/2]`。复算流量 `a` 视为精确值，差值区间为 `[a-b-s/2, a-b+s/2]`，服务端以 `Decimal` 计算并按三位小数输出 `delta_min`、`delta_max`。区间与允差线 `t` 的位置给出三种判定：

| 判定码 | 条件 | 值班处理 |
|---|---|---|
| `TOL_OK` | 差值区间整体满足 `|差值| <= t`（端点压线也算） | 可按显示值签认 |
| `TOL_HOLD` | 区间跨过允差线，部分在允差内、部分超差 | 无法证明不超差，暂缓签认，等精测 |
| `TOL_OVER` | 差值区间整体超出允差 | 确定超差，不得签认 |

存在任一 `TOL_HOLD` 或 `TOL_OVER` 时，本批 `rounding.signable=false`，值班复核的「确认」会被 `REVIEW_ROUNDED` 拒绝，可先「退回」并注明等精测；精测记录晚到后用精确账（原两列格式）重跑，精确账仍按 `MATCH/AMOUNT_DELTA` 原办法核对，原舍入批次及其依据继续保留可查。同一对输入字节重跑（含同一份精测）生成同一批次，不新增复核批次。

同一对输入字节与规则版本生成同一批次，导出包含两个文件摘要、证据行、单边差异和复核修订记录。复核保存前检查当前版本，在有隔离、差异或退回时必须填写意见。
