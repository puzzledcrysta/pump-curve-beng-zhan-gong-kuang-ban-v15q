# 泵站工况板

供水泵房运行分析员可用本地工作台处理工况单，复查泵与管线交点并与独立清单逐笔核对。

按公共扬程叠加各泵流量，把曲线转折投影到总流量，逐段求与实测管线曲线交点。

## 启动

```sh
docker compose up --build
```

打开 http://127.0.0.1:18313 并运行随附样例。可以在「导入来源与外部账」上传自己的 CSV，也可以编辑表单中的样例。数据保存于 Compose 卷 `ledger`。使用 `APP_PORT` 可覆盖宿主端口。

## 工作步骤

1. 检查「实测导入」与「测点字段」，定位导入坏行与字段归一结果。
2. 在「异常工况」区分冲突、业务拒绝、重传与旧版本。
3. 打开「并联工况」并点击任意记录的「查看依据」。
4. 在「工况对读」检查金额或用量差异。通过「泵站批次」复算原文件，通过「值班复核」提交意见并下载证据。

接口定义见 `/openapi.json`。字段、允许区间及算例见 [数据字典](docs/DATA-DICTIONARY.md)，模块和回归测试见 [测试登记](docs/DEPTH.md)。

## 验证

```sh
docker compose config --quiet
docker compose exec -T app pytest -q
```

`sample_data/shift.csv` 是班次数据，`sample_data/external.csv` 是独立账样例。`cases.csv` 固定业务反例，`legacy.csv` 和 `truncated.csv` 用于验证历史格式与断行。

`sample_data/rounded.csv` 是只给四舍五入显示值、舍入步长和允差的外部账样例（四列表头）。「工况对读」按差值区间判定：区间整体在允差内可签认（`TOL_OK`），跨过允差线则列「待精测」（`TOL_HOLD`）并拦截值班复核的「确认」，整体超差为 `TOL_OVER`。精测记录晚到后用精确账重跑即可签认，原舍入批次与依据仍保留在「泵站批次」中；同一份精测重跑不产生新批次，精确外账始终按原逐笔差值办法核对。
